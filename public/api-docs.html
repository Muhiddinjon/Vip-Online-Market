API Documentation

VipOnlineMarket — Flutter client app uchun REST API. Barcha javoblar JSON formatida qaytariladi.

Base URL: https://your-domain.com/api
Til parametri: Ko'p tilli maydonlar (nom, tavsif) uchun so'rovga ?lang=uz qo'shing.
Qiymatlar: uz (standart), en, tr
Xato formati: 
{
  "message": "Xato matni",
  "errors": { // validation xatolari uchun
    "field": ["Xato matni"]
  }
}

Autentifikatsiya

Himoyalangan endpointlarga murojaat qilish uchun Authorization: Bearer <token> header qo'shing.

POST /auth/otp/send SMS orqali tasdiqlash kodi yuborish

Request body

MaydonTurHolatTavsif
phonestringMajburiyTelefon raqam, mas: +998901234567
POST /api/auth/otp/send
Content-Type: application/json

{
  "phone": "+998901234567"
}

Response 200

{
  "message": "SMS yuborildi."
}
POST /auth/otp/verify OTP kodni tasdiqlash va token olish

Request body

MaydonTurHolatTavsif
phonestringMajburiyTelefon raqam
codestringMajburiy6 xonali SMS kodi
POST /api/auth/otp/verify
Content-Type: application/json

{
  "phone": "+998901234567",
  "code":  "123456"
}

Response 200

{
  "token": "1|abc123...",
  "user": {
    "id":    42,
    "name":  "Mijoz",
    "phone": "+998901234567",
    "role":  "customer"
  }
}

Buyurtma statuslari

StatusTavsifBekor qilish
pendingYangi buyurtma, restoran kutmoqda✅ Mumkin
confirmedRestoran qabul qildi✅ Mumkin
preparingTayyorlanmoqda❌ Mumkin emas
readyTayyor, kuryer kutmoqda❌ Mumkin emas
deliveringKuryer yetkazmoqda❌ Mumkin emas
deliveredYetkazildi ✓❌ Mumkin emas
cancelledBekor qilindi—

POST /orders/{id}/cancel 🔒 Auth Buyurtmani bekor qilish

Faqat pending va confirmed statusdagi buyurtmalarni bekor qilsa bo'ladi.

POST /api/orders/101/cancel
Authorization: Bearer <token>

Response 200 — muvaffaqiyatli bekor qilindi

{
  "data": {
    "id":     101,
    "status": "cancelled",
    // ...
  }
}

Response 422 — bekor qilib bo'lmaydi

{
  "message": "Bu buyurtmani bekor qilib bo'lmaydi. Restoran allaqachon tayyorlashni boshlagan."
}
