API Documentation

VipOnlineMarket — Flutter client app uchun REST API. Barcha javoblar JSON formatida qaytariladi.

Base URL: https://your-domain.com/api
Til parametri: Ko'p tilli maydonlar (nom, tavsif) uchun so'rovga ?lang=uz qo'shing.
Qiymatlar: uz (standart), en, tr
Xato formati: 
{
  "message": "Xato matni",
  "errors": { // validation xatolari uchun
    "field": ["Xato matni"]
  }
}

O'zgarishlar jurnali

v1.2 — 2026-05-28

GET /catalog/shop-categories — yangi endpoint: katta savdo kategoriyalari (Kiyimlar, Gadgetlar…)
GET /catalog/advertisements — yangi endpoint: faol reklamalar (queue bo'yicha)

Kategoriyalar — javobga image (URL) qo'shildi
Mahsulotlar — javobga sale (chegirma %) va sale_price (chegirmali narx) qo'shildi

v1.1 — 2026-05-27

Restoranlar — delivery_time, delivery_fee qo'shildi
